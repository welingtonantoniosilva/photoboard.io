Instruções

Bem-vindo ao jogo PHOTO BOARD! Para garantir que você tenha a melhor experiência, siga as regras abaixo:

  1. Use o MOUSE para alterar o pixel.
  2. Utilize o ENIGMA para revelar as informações da Imagem.
  3. Aperte o botão Validar Resposta para informações de acerto.
  4. Aperte o botão Revelar Enigma para visualizar Imagem.

O jogo PHOTO BOARD! foi baseado em algoritmos que servem para comprimir dados de imagem.
